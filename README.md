## Project Summary  
This project is a **Package Management System** designed for businesses. It enables the creation and management of customers and businesses, the assignment of packages to customers, and the tracking of package locations via GPS coordinates. Users can view the delivery path on a static map.

- **Frontend**: Built with HTML, CSS, JavaScript, using **jQuery** and **jQuery Validation** for form handling and dynamic behavior.  
- **Backend**: Powered by **Node.js** and **Express**, with **MongoDB** for data storage, using **Mongoose** as the ODM.  
- **APIs Used**:  
  - **LocationIQ** for geocoding customer addresses.  
  - **Geoapify** for rendering static delivery path maps.
